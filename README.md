# Brush Up
This is a toothbrush training game for children. 
The 'UH3-Prep" build is not currently public.
This build willl be used to conduct a trial of the game with 300 families with an autistic child.
Before the trial begins, we need to test the functionality of the build we will use.


## Testing Hardware
Test each of 4 platforms. Device can be a little old but must run lastest OS:
-  iPad (ios 18+ / Safari)
-  iPhone (ios 18+ / Safari)
-  Android tablet (android 16 / Chrome)
-  Android phone (android 16 / Chrome)

## Testing Scope
Each family in the test will be given a personal link (qr) to the installation landing page.
They are expected to open this on their own phone 
and then use it to help install the software on their child's device.

Please replicate this process 
   for example- follow the link on an android phone and then install on an iPad


### Test these features as "adult":
- Installer/Onboarding app
#### [switch to the child device]
- PWA Installation
- Phone based Account Authentication
- Family Account Set up in-app
  - realtime reports (notification)
- Child Account setup (in app)

### Test these as "child":
- Launch Game
- Toothbrushing: Digital Mirror / 3D character / Song
- pause/resume
- change 'flavor', color, volume
- Matching Game: Win/ Lose/ easrn points
- Prize selection
